# Implementation Reports

One markdown file per completed task. Agents write here at the end of every task (see `../ai-workflow.md` §4).

**Filename:** `YYYY-MM-DD_<short-slug>.md` (e.g. `2026-05-28_filing-calendar-engine.md`)

These are the running changelog for the next agent — what changed, key decisions, deviations, follow-ups, verification status. Keep them tight.
