BotStackHQ Phase 1 — four critical data flows

1
Client sends WhatsApp message
Text query, document upload, or reply to collection request
2
Meta API → API Gateway webhook handler
Signature verified (X-Hub-Signature-256), timestamp validated
3
Webhook Handler Lambda — classify intent
text document status update
4
Enqueue → SQS LLM inference queue
Message routed for AI agent processing
5
AI Agent Lambda → LangChain.js → GPT-4o
pgvector RAG retrieval if knowledge base context needed
6
Response generated → SQS WhatsApp dispatch queue
Conversation state written to RDS PostgreSQL
7
Notification Lambda → Meta WhatsApp API → Client
Message delivered, delivery receipt logged
8
WebSocket push → CA dashboard
New client message visible in conversation monitor in real-time
1
EventBridge Scheduler fires — T-12 days before deadline

2
Workflow Engine Lambda triggered
Fetch client filing config and contact details from RDS
3
AI Agent generates input collection message
Filing-type specific template — GSTR-1 requires sales register, GSTR-3B requires ITC details
4
SQS WhatsApp dispatch → Notification Lambda → Client
Meta pre-approved template message sent to client
5
Workflow state updated in RDS
Status: input_requested. Next trigger scheduled: T-7 days
6
T-7 reminder fires if no client response
Gentle reminder via WhatsApp. T-3 escalation scheduled
7
T-3 escalation fires — CA notified + urgent client reminder
CA receives dashboard alert. Client gets urgent WhatsApp
8
Client responds → inputs collected → CA notified
Workflow state: inputs_complete. CA ready to file
1
Client sends PDF via WhatsApp
GST certificate, TDS certificate, invoice, or other filing document
2
Webhook Handler downloads media from Meta API
Media URL from webhook payload, authenticated download
3
File uploaded to S3
Key: workspaces/{workspace_id}/clients/{client_id}/filings/{filing_id}/{filename}
4
S3 key written to RDS document record
Status: uploaded, awaiting_extraction
5
SQS document processing queue → Python FastAPI Lambda
Document AI service triggered via container Lambda
6
Field extraction — GSTIN, ARN, turnover, period, TDS amounts
PyMuPDF + pdfplumber. OCR via pytesseract for scanned docs
7
Validate against filing checklist
All required fields present? Values plausible? Filing period correct?
8
If incomplete → Notification Lambda → client (missing fields)
Agent lists exactly what is missing or incorrect
9
If complete → CA notified — inputs ready to file
Dashboard alert + WhatsApp to CA. WebSocket push updates status live
1
CA files report on GST / TDS portal (external action)

2
CA marks filing complete on dashboard

3

4
Workflow Engine triggered — filing confirmed event

5
Confirmation Agent generates message

6
SQS WhatsApp dispatch → Notification Lambda → Client

7
Immutable audit log entry written to RDS

8
WebSocket push → CA dashboard — status: confirmed
